Sobre mí

Soy Ubaldo Sánchez González y estoy comenzando mi formación como ingeniero en sistemas. Elegí esta carrera porque me gusta resolver problemas: desarmar una idea, entender qué piezas necesita y volver a armarla de forma que funcione.

03

Lo que quiero aprender

  1. Programación orientada a objetos

    Dominar clases, herencia y buenas prácticas con Java o C++ para escribir código ordenado y reutilizable.

  2. Estructuras de datos y algoritmos

    Entender listas, pilas, colas y árboles, y saber cuándo conviene usar cada uno para que un programa sea eficiente.

  3. Desarrollo web full-stack

    Construir aplicaciones completas: interfaz, servidor y base de datos, con control de versiones usando Git y GitHub.

  4. Bases de datos y SQL

    Diseñar modelos relacionales, escribir consultas y cuidar la integridad de la información.

  5. Fundamentos de inteligencia artificial

    Comprender el aprendizaje automático desde las matemáticas, para aplicarlo después en proyectos reales.
